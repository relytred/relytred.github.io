TOP LAYER TOWN
Every control below puts something in the browser's top layer, which no z-index can outrank. Open a guide first, then pick a fight.

Guide

Auto-display guides show on their own. For an on-demand one, enter its id or name. A guide only reaches the top layer if its payload sets attributes.popover.enabled.

Full-screen dialog

showModal() enters the top layer and blocks the rest of the document. That also makes the guide unhittable, so the readout below reports cannot tell — judge this one by looking at the pixels. The non-modal show() is the control case: same box, normal layer, so a guide at z-index: 300000 should still beat it.

Fullscreen API

requestFullscreen() also lands in the top layer, and hides everything outside the fullscreen element's subtree. The second button asks for fullscreen on the modal dialog, which puts one element in the top layer twice.

Popovers

manual stacks above whatever opened before it. auto additionally closes other auto popovers — a guide using manual should survive it. The corner popover overlaps nothing, so a guide has no reason to react to it.

Hostile host

War mode makes this page re-raise its own popover every time anything else enters the top layer. Whoever wins, the page must settle rather than flicker forever — watch the re-raise counter below.
