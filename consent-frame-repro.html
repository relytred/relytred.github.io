Consent does not propagate to child frames

pendo.updateCookieConsent() only updates the frame it is called in. The identity that follows a re-grant is broadcast to child frames, but each child still evaluates it against its own stale (denied) consent policy and drops it.

How to reproduce

  1. Load this page. Both frames start on the strictlyNecessary tier, which sets trackVisitors: false, so both collapse to __cookieless_visitor__.
  2. Click Grant identity consent. That calls updateCookieConsent(['strictlyNecessary', 'functional']) in the top frame only.
  3. The top frame fires identifyRequested; this page answers it with pendo.identify(), and the top frame picks up the real visitor ID.
  4. Watch the child frame: it stays on __cookieless_visitor__, and its console shows Ignoring visitor id … while identity consent is dnt.
